## RETAKE CANCEL IMPLEMENTATION

Для выбранного кадра S3 создаётся временный набор кадров и временный фильтр.
Кнопка «Отмена» в верхней панели камеры возвращает пользователя к review.
Исходный review остаётся смонтированным, но скрытым: подпись, фильтр, три
оригинальных кадра и готовый JPEG сохраняются. При завершении снимка черновик
заменяет кадры сессии, после чего S3 обновляется обычным способом.

У каждой попытки есть уникальный token: позднее завершение загрузки из отменённой
попытки не может записать кадры в следующую попытку. Полная пересъёмка серии
использует прежнюю механику.

Проверена отмена каждого из трёх слотов, отмена во время отсчёта, изменение
фильтра в черновике, сохранение подписи, побайтово неизменный JPEG и тот же
download URL, неизменность recent photos, поздняя загрузка и поздний media stream.

## MULTI-SESSION RESULTS

Три последовательные сессии выполнены в одном документе, без reload. В каждой:

- Начальные слоты пусты; три новых захвата совпадают с кадрами review по порядку.
- Завершённая пересъёмка заменяет только второй кадр.
- Фильтр меняет готовую S3; fullscreen и скачивание работают.
- JPEG скачивается с теми же байтами, что отображаются в готовом результате.
- Количество recent photos растёт 1 → 2 → 3; скачивание и удаление из ленты работают.
- Все полученные camera tracks остановлены после перехода к review или выхода.

## SHARE IMPLEMENTATION

Готовая S3 преобразуется в `File` типа `image/jpeg`, имя
`inc-soul-layout-S3.jpg`. Object URL для скачивания создаётся из этого же файла.
Share не вызывает canvas export и не меняет качество.

Кнопка появляется только при наличии `navigator.share`, `navigator.canShare`
и положительной проверке `{ files: [готовый JPEG] }`. Исключение проверки
поддержки скрывает кнопку. Вызов `share` происходит непосредственно из нажатия,
до любого `await`. Во время подготовки результата и незавершённого вызова
повторная отправка заблокирована.

`AbortError` обрабатывается без ошибки интерфейса. Прочие ошибки предлагают
скачать JPEG через существующее «Скачать / сохранить».

Браузерные проверки с подменой Web Share API подтверждают совпадение байтов
Share/download, user activation, отсутствие повторной сборки, недоступность
каждого API, отсутствие поддержки файлов, исключение `canShare`, отмену,
ошибку передачи, повторное нажатие и актуальность JPEG после изменения подписи.
При недоступном Share проверено реальное скачивание браузером.

## BROWSER LIMITATIONS / MANUAL TESTS REQUIRED

Нативное системное share sheet не автоматизировано: API подменён только в
браузерном тесте, приложение использует реальный API. Перед релизом на HTTPS
Preview нужны проверки на физических устройствах:

1. iPhone / Safari и Android / Chrome: запрос разрешения, три фото, отмена и
   завершение пересъёмки, три сессии, выключение индикатора камеры.
2. «Поделиться»: системное окно получает JPEG-файл S3; проверить импорт файла
   в выбранное приложение и отдельно закрытие окна без ошибки.
3. Браузер без file sharing: кнопка Share отсутствует, JPEG скачивается.

Поддержка зависит от браузера, контекста HTTPS и Permissions Policy;
см. [MDN: Navigator.share](https://developer.mozilla.org/en-US/docs/Web/API/Navigator/share).
